# s 365 Attempting to set fire to crops etc
A person commits a summary offence if he or she—
(a) attempts unlawfully to set fire to any such thing as is mentioned in section 364 ; or
(b) wilfully and unlawfully sets fire to anything which is so situated that any such thing as is mentioned in section 364 is likely to catch fire from it.
Penalty — Imprisonment for 7 years.
