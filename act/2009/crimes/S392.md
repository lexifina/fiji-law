# s 392 Savings provisions
(1) Nothing in this Act affects the validity of any court proceedings for an offence under the Penal Code which has been commenced or conducted prior to the commencement of this Act.
(2) When imposing sentences for any offence under the Penal Code which was committed prior to the commencement of this Act, the court shall apply the penalties prescribed for that offence by the Penal Code.
