# s 25 Continuity of perfection
(1) A security interest is continuously perfected for the purposes of this Act, if—
(a) the security interest is perfected under this Act;
(b) the security interest is subsequently perfected in another way under this Act; and
(c) there is no intervening period during which the security interest is unperfected.
(2) A transferee of a security interest has the same priority with respect to perfection of the security interest as the transferor had at the time of the transfer.
