# O 4.2
NUMBER OF SPECIMENS FOR TESTS
Eleven batteries are required to assess compliance with this Standard, ie to apply the mandatory tests of Table 4.2. An additional battery is required for the optional test 4 of Table 4.3, if it is to be applied. This arrangement allows an extra battery if the mandatory tests 4, 5, 6, 7, 8 or 9 of Table 4.2 or the optional test 4 of Table 4.3 are to be repeated.
