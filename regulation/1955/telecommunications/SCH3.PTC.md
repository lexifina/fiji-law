# PART C TELEPRINTER PRIVATE WIRES (LEASED CIRCUITS) AND OTHER TELEGRAPH FACILITIES
1. | Annual rental for a teleprinter private wire— |
| (a) | for local line between a subscriber’s premises within the standard rental area and the local telephone exchange … | 81
| (b) | for line extending beyond the standard rental area of a telephone exchange or interconnecting 2 exchanges in the same unit fee area— |
| | (i) | using subscriber cable … | 27 per additional 500 metres or part thereof
| | (ii) | using trunk telephone cable … | 81 per radial km or part thereof
| | (iii) | using telegraph transmission equipment … | Such amount as the Permanent Secretary may determine
| (c) | for teleprinter and associated apparatus— |
| | (i) | Send/receive page teleprinter … | 468
| | (ii) | Send/receive page teleprinter with perforator and tape reader … | 630
| | (iii) | Receive only printing perforator … | 420
| | (iv) | Keyboard perforator … | 180
| | (v) | Tape reader … | 180
2. | Connection fees for a teleprinter private wire— |
| | (i) | for each send/receive teleprinter … | 80
| | (ii) | for any other machine referred to in Item 1(c) … | 60
| | (iii) | for a telegraph transmission channel … | 70
3. | For line interconnecting 2 exchanges in different charging zones or for facilities not specified in this Part … | Such amount as the Permanent Secretary may determine
