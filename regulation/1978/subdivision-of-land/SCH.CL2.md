# reg 2
If engineering plans are required to be submitted the following additional fees are payable—
ENGINEERING PLAN EXAMINATION
(a) | Basic fee … | $68
| (plus fees calculated under paragraphs (b) to (f))
(b) | For engineering works of a value exceeding $2,000 but not exceeding $5,000 … | $34
(c) | For the value of work exceeding $5,000 but not exceeding $10,000 … | $68
(d) | For the value of work exceeding $10,000 but not exceeding $15,000 … | $136
(e) | For the value of work exceeding $15,000 but not exceeding $20,000 … | $170
(f) | For the value of work exceeding $20,000 … | $170 + $8 for every $1,000 (or part thereof) value in excess of $20,000.
