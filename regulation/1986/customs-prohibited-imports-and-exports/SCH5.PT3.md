# PART 3 FIRE EXTINGUISHERS ETC
(a) import halons or halon fire extinguishers;
(b) import any motor vehicle that incorporates automotive air-conditioners which contain any controlled substance listed in Parts 1 and 2A;
(c) import any automotive air-conditioner which contains any controlled substance listed in Parts 1 and 2A;
(d) import any air-conditioner, air conditioner unit, refrigerator or refrigeration unit including any compressor, that contains or uses any controlled substance listed in Parts 1, 2 and 2A; and
(e) import any apparatus or equipment containing any controlled substance listed in Parts 1, 2 and 2A.
