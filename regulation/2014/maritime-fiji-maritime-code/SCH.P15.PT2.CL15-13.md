# reg 15.13
List of All Persons onboard
15.13.1 For all class of ships a list of all persons on board shall be kept ashore with owners/operators or agents so that it will be readily available to the proper officer in the case of an emergency. Such list shall contain—
(a)the name and/or identification number of the ship; and
(b)the name and address of each person on board the ship.
15.13.2 Any person who fails to comply with subparagraph 15.13.1 commits an infringement offence and is liable to a fine not exceeding $2,000.
