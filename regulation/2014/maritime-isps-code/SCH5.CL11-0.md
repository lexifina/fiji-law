# reg 11.0 Prohibited RSO actions
It shall be an administrative offence for a Recognised Security Organisation (RSO) to set security levels, approve ship or port facility security assessments, approve ship security plans without the Administration’s approval or port facility security plans, or exercise ship control and compliance measures. A violation under this section is punishable by—
a.$50,000 fine per violation; and
b.Revocation of RSO certification.
