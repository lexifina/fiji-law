# reg 17.0 Personal flotation devices
(1) Each person on board a commercial jet boat must be provided with a personal flotation device that complies with subparagraph (2) or (3).
(2) Except as provided in subparagraph (3), the personal flotation device must be of a type 401, type 402 or type 406 specialist personal flotation device except that the device does not need to be fitted with light retro-reflective tape.
(3) The Chief Executive Officer may accept the use of another type of personal flotation device equivalent to types 401, 402 or 406.
