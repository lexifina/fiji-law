# reg 13 Ships cargo gear general
(1) The working load for each set of gear shall not exceed the safe working load for that gear as marked on the boom. In the absence of markings of the safe working load on the boom, the safe working load for each set of gear as specified by the cargo gear register shall not be exceeded.
(2) Cargo handling gear, any part of which is visibly unsafe, shall not be used until such part is made safe.
