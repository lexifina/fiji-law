# reg 3 Application for licence
(1) For the purpose of section 5 of the Act—
(a)the application form is set out in Schedule 1; and
(b)the application processing fee is $3,000 (exclusive of value added tax).
(2) The application processing fee under subregulation (1)(b) is non-refundable.
(3) The Bank may require additional information from the applicant for processing an application.
