# reg B3.0
Foaming Agents
3.1 Foaming agents are more effective for detection of small leaks, as large leaks tend to blow the solution away from the leak without forming a bubble. Care in applying the solution slowly with a brush will provide easier detection of large leaks.
3.2 The foaming agent should be a proprietary leak test solution, formulated specifically for the purpose. It is essential that fresh solution be used, that the whole of the surface to be tested is coated and that time be allowed for bubbles to foam. All areas under test should be able to be observed during the test.
