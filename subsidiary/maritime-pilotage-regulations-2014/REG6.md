# reg 6 Classes of pilot licence
(1) The Chief Executive Officer may issue 3 classes of pilot licences.
(2) The classes of pilot licences that may be issued and the classes of ships for which each class of licence shall be valid shall be as shown in the table below—
Table 1 — Classes of pilot licence
Class 1 | Valid for all size of ships
Class 2 | Valid for all size of ships not exceeding 185 metres in overall length
Class 3 | Valid for all size of ships not exceeding 150 metres in overall length
